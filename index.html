How to use the AI demos

1

Get a free Gemini API key at aistudio.google.com/apikey — sign in with Google, click Create API key. No credit card needed.

2

Open Call Simulator or Card Generator. You'll see a key input field at the top of each page.

3

Paste your key and click Save Key. It stays in your browser session only — never stored anywhere, never sent to us.
