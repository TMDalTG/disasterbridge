# 🌐 DisasterBridge

> AI-powered emergency response coordination for individuals with disabilities during natural disasters.

**Live Demo:** [View on GitHub Pages](https://YOUR-USERNAME.github.io/disasterbridge/)

## What it does

DisasterBridge uses Google Gemini AI to address the two-layer risk faced by disabled individuals during disasters: immediate physical danger AND loss of access to support systems.

### Three demos

| Demo | Description | API Key? |
|------|-------------|----------|
| 🗺️ [Risk Map](simulation.html) | Hurricane Beryl vulnerability map — Houston scenario | No |
| 📞 [Call Simulator](call.html) | AI welfare calls adapted per disability profile | Yes (free) |
| 🪪 [Responder Cards](card.html) | Instant first responder briefing card generation | Yes (free) |

## Setup

### Get a free Gemini API key

1. Go to [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
2. Sign in with any Google account
3. Click **Create API key** — no credit card needed

### Use the app

The API key is entered **in the browser** — it stays in your session only. It is never:
- Stored in the code
- Committed to this repo
- Sent to any server other than Google's API

This means the repo can be fully public with zero security risk.
